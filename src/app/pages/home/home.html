Transforms

Understanding Angular Pipes

Pipes format and transform data directly inside your templates, leaving original data pristine.

String Manipulation

Uppercase Pipe

Formats any standard string to uppercase, which is ideal for titles or emphasis.

{{ "{{ demoText() | uppercase }}" }}
Formatted: {{ demoText() | uppercase }}
Numbers & Currency

Currency Pipe

Converts raw numeric variables to formatted financial strings with symbols.

{{ "{{ demoPrice() | currency }}" }}
Formatted: {{ demoPrice() | currency }}
Dates & Times

Date Pipe

Formats Javascript Date instances or timestamps into customizable local formats.

{{ "{{ demoDate() | date:'mediumDate' }}" }}
Formatted: {{ demoDate() | date:'mediumDate' }}
