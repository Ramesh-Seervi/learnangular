Understanding Angular Directives

Directives allow you to attach behaviors, modify layouts, or build custom elements inside Angular templates.

Type 1

Components

Directives with a template. These form the building blocks of your UI structure.

<app-header></app-header>
Type 2

Structural

Directives that alter DOM layouts by adding, removing, or replacing elements dynamically.

@if (isLoggedIn()) {
  <p>Welcome back!</p>
}
Type 3

Attributes

Directives that modify the style, property, or behavior of an existing element.

<div [appHighlight]="'red'">
  Hover to test glow
</div>
